### Query.resolveIngestEndpoint

Resolve a stream key to ingest endpoints for StreamCrafter. Returns node-specific advertised protocols. A requested protocol filters candidates before ranking; it is not permission to substitute a different protocol.

## Types

### CreatePushTargetInput

**input_object**

- **platform**: `String` — Platform identifier (twitch, youtube, facebook, kick, x, custom).
- **name**: `String!` — User-friendly label for this target.
- **targetUri**: `String!` — Full target URI including stream key (e.g., rtmp://live.twitch.tv/app/live_xxxx).

### CreateStreamInput

**input_object**

Input for creating a new live stream.

- **name**: `String!` — Human-readable name for the stream.
- **description**: `String` — Optional description for the stream.
- **record**: `Boolean` — Enable DVR recording (default: false).
- **ingestMode**: `IngestMode` ([IngestMode](/builders/api-schema/shared/#ingestmode)) — Source ingest model. Defaults to PUSH.
- **pullSource**: `PullSourceInput` ([PullSourceInput](/builders/api-schema/streams/#pullsourceinput)) — Pull-source configuration. Required when ingestMode is PULL.
- **sourceLocation**: `SourceLocationInput` ([SourceLocationInput](/builders/api-schema/streams/#sourcelocationinput)) — Where the source may be ingested. Omitted means ANY. Required for private and multicast pull sources.

### SourceLocationInput

**input_object**

Replaces the stream&#39;s own ingest restriction. Private and multicast pull sources require RESTRICTED with clusters that allow private pull sources.

- **mode**: `SourceLocationMode!` ([SourceLocationMode](/builders/api-schema/shared/#sourcelocationmode)) — ANY or RESTRICTED. CUSTOM is rejected.
- **clusters**: `[SourceLocationClusterInput!]!` ([SourceLocationClusterInput](/builders/api-schema/streams/#sourcelocationclusterinput)) — Required and non-empty for RESTRICTED; must be empty for ANY.
- **avoidNodeIds**: `[ID!]!` — Nodes the source must never run on. Only nodes of clusters the tenant owns are accepted.

### UpdateStreamInput

**input_object**

Input for updating an existing stream. All fields are optional - only provided fields are updated.

- **name**: `String` — New name for the stream.
- **description**: `String` — New description for the stream.
- **record**: `Boolean` — Enable or disable DVR recording.
- **ingestMode**: `IngestMode` ([IngestMode](/builders/api-schema/shared/#ingestmode)) — Ingest model cannot be changed after create; sending a different value returns a validation error.
- **pullSource**: `PullSourceInput` ([PullSourceInput](/builders/api-schema/streams/#pullsourceinput)) — Update the pull-source configuration for an existing pull stream.
- **sourceLocation**: `SourceLocationInput` ([SourceLocationInput](/builders/api-schema/streams/#sourcelocationinput)) — Replace where the source may be ingested. Omitted keeps the current location. Rejected for managed streams.
- **dvrChapterMode**: `DVRChapterMode` ([DVRChapterMode](/builders/api-schema/shared/#dvrchaptermode)) — Historical chapter rotation mode. Snapshotted onto the DVR artifact at StartDVR; changes take effect on the next recording, not in-flight. NONE means rolling DVR playback only: recording still runs, but no finalized chapter artifacts are produced for historical replay.
- **dvrChapterIntervalSeconds**: `Int` — Chapter interval in seconds. Required when dvrChapterMode = FIXED_INTERVAL. Minimum 3600 (1 hour).
- **monitoring**: `MonitoringToggle` ([MonitoringToggle](/builders/api-schema/shared/#monitoringtoggle)) — Per-stream Skipper monitoring override. INHERIT follows the tenant tier.
