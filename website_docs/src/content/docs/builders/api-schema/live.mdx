## Subscriptions

### Subscription.liveConnectionEvents

Individual viewer connection/disconnection events. High volume - filter by streamId in production for performance.

```graphql

  streamId: ID
): ConnectionEvent!
```

### Subscription.tenantEvents

Public events of the current tenant, as webhooks deliver them: stream lifecycle, clip, recording, and upload lifecycle, multistream status, API tokens, billing, account, and custom domain events. Each event&#39;s data is the registered payload of its type. Pass types to receive only those event types (e.g. [&#34;clip.ready&#34;, &#34;clip.failed&#34;]); pass streamId to receive only events whose payload names that stream.

```graphql
tenantEvents(
  types: [String!]
  streamId: ID
): PublicEvent!
```

**Returns:** `PublicEvent!` ([PublicEvent](/builders/api-schema/live/#publicevent))

**Arguments**

- `types`: `[String!]`
- `streamId`: `ID`

**SDK**

| Operation | TypeScript | Go | Python |
| --- | --- | --- | --- |
| TenantEvents | `TenantEventsDocument` | `SubscribeTenantEvents` | `tenant_events` (async) |

### PublicEvent

**object**

A public tenant event as its owning service emitted it. data is the registered message of type, unchanged; webhooks deliver the same message.

- **id**: `ID!` — Event ID, stable across redeliveries.
- **type**: `String!` — Registered event type, e.g. stream.live.
- **time**: `Time!` ([Time](/builders/api-schema/shared/#time)) — When the state change committed.
- **subject**: `String!` — The aggregate the event belongs to, as &lt;aggregate&gt;/&lt;id&gt;, e.g. streams/&lt;stream id&gt;.
- **data**: `PublicEventData!` ([PublicEventData](/builders/api-schema/live/#publiceventdata))
