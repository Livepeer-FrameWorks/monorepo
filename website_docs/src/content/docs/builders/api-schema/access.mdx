Resolve a playback ID to viewer endpoints (HLS, DASH, etc.). Used by players to get the optimal CDN endpoint for playback.

```graphql

  contentId: String!

): ViewerEndpointResponse
```

**Returns:** `ViewerEndpointResponse` ([ViewerEndpointResponse](/builders/api-schema/access/#viewerendpointresponse))

- `protocol`: `MediaViewerProtocol` ([MediaViewerProtocol](/builders/api-schema/access/#mediaviewerprotocol)) — Optional playback constraint. A different format is never substituted. Omit to select a node with any playable Mist output and receive its full catalog.

### Mutation.setPlaybackPolicy

Set or clear the playback access policy on a stream, VOD asset, or clip. Exactly one of streamId / vodAssetId / clipId must be set in the input. ### CreateSigningKeySuccess

**object**

### PlaybackAccessDecision

**object**

Structured result of a dry-run policy evaluation. Mirrors Foghorn&#39;s PlaybackDecision struct.

- **allowed**: `Boolean!`
- **policyType**: `String!` — Resolved policy type: &#39;public&#39; &#124; &#39;jwt&#39; &#124; &#39;webhook&#39; &#124; &#39;&#39; when no policy was found.
- **reason**: `String` — Empty on allow; deny reason token (e.g. &#39;jwt-expired&#39;, &#39;webhook-deny-403&#39;) otherwise.
- **detail**: `String` — Free-form context for the operator (verifier error string, HTTP status as text).
- **kid**: `String` — JWT key ID claimed by the token (extracted before verification).
- **claimsJson**: `String` — JSON-encoded JWT claims map. On allow, the verified claims. On deny, an unverified parse of the payload — useful for diagnosing aud / required- claim mismatches but never trustworthy as an auth signal.
- **webhookStatus**: `Int` — HTTP status code from the customer webhook (0 if no call was made).
- **webhookLatencyMs**: `Int` — End-to-end RTT for the webhook call in milliseconds (0 if no call was made).
- **resolvedInternalName**: `String` — Internal MistServer name the evaluator resolved against. Always populated when a target was found.

### SigningKey

**object**

A customer-managed signing key for issuing viewer playback JWTs. The private key is returned exactly once at creation time (in CreateSigningKeySuccess); FrameWorks stores only the public key. Up to 10 active keys per tenant.

Implements [Node](/builders/api-schema/shared/#node).

- **id**: `ID!`
- **kid**: `String!` — Short ID embedded in JWT header (`kid`) for fast key lookup.
- **name**: `String!` — Customer-supplied label.
- **algorithm**: `SigningKeyAlgorithm!` ([SigningKeyAlgorithm](/builders/api-schema/access/#signingkeyalgorithm)) — Algorithm — ES256 only for v1.
- **publicKeyPem**: `String!` — Public key in PEM format. The private key is never stored.
- **status**: `SigningKeyStatus!` ([SigningKeyStatus](/builders/api-schema/access/#signingkeystatus)) — Lifecycle status.
- **createdAt**: `Time!` ([Time](/builders/api-schema/shared/#time))
- **lastUsedAt**: `Time` ([Time](/builders/api-schema/shared/#time)) — Last time a JWT signed by this key successfully verified at playback.
- **revokedAt**: `Time` ([Time](/builders/api-schema/shared/#time)) — When the key was revoked (null if active).

### TestPlaybackAccessInput

**input_object**

Inputs for testPlaybackAccess. Exactly one of playbackId / internalName must be set (the server rejects both-set and neither-set). viewerToken is required for JWT policies and is forwarded to the webhook payload for webhook policies. fireWebhook gates a real outbound HTTPS call to the customer URL. That call uses the same SSRF-hardened evaluator path as live viewer admission, and customer endpoints may log, rate-limit, or trigger side effects from the test request. When playbackId is supplied, the server resolves the canonical internalName before invoking the evaluator so webhook payloads carry the same streamName the live USER_NEW path would.

- **playbackId**: `String`
- **internalName**: `String`
- **viewerToken**: `String` — JWT to test (required for type=jwt; passed through in the webhook payload for type=webhook).
- **viewerIp**: `String`
- **requestUrl**: `String`
- **connector**: `String`
- **sessionId**: `String`
- **fireWebhook**: `Boolean` — Webhook policies only: when true, Foghorn will POST to the configured customer URL with an HMAC-signed payload (same path the live evaluator uses). When false, the evaluator returns reason=&#34;webhook-test-skipped&#34; without making the call so operators can inspect the resolved policy without side effects.
- **origin**: `String` — Origin header to test the policy&#39;s allowed origins against.
- **referer**: `String` — Referer header, used when origin is empty.
