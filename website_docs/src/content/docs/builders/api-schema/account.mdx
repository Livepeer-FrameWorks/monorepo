### CustomDomainStatus

**object**

Verification + certificate lifecycle for a tenant&#39;s BYO domain. Returned by Navigator&#39;s GetCustomDomainStatus and surfaced verbatim so the dashboard can guide the operator through the manual DNS setup.

- **domain**: `String!` — The domain Navigator is tracking (mirrors Tenant.customDomain).
- **state**: `String!` — pending_verification &#124; verified &#124; pending_alias &#124; cert_issuing &#124; cert_issued &#124; cert_failed &#124; verification_failed &#124; tearing_down — verbatim from Navigator. pending_alias means the CNAMEs are verified and the domain waits for the tenant alias certificate. verification_failed means the CNAMEs were not verified within the fixed verification period.
- **requiredTrafficCname**: `String` — CNAME the operator points their public hostname at so the platform&#39;s TLS ingress receives traffic.
- **requiredAcmeChallengeCname**: `String` — CNAME the operator points `_acme-challenge.&lt;their-domain&gt;` at so Navigator can complete DNS-01 issuance via the `acme-dns.&lt;root&gt;` delegated subzone.
- **lastVerifiedAt**: `Time` ([Time](/builders/api-schema/shared/#time)) — Wall-clock UTC of the last successful verification check (null when never).
- **certIssuedAt**: `Time` ([Time](/builders/api-schema/shared/#time)) — Wall-clock UTC of the most recent successful cert issuance (null when never).
- **certExpiresAt**: `Time` ([Time](/builders/api-schema/shared/#time)) — Wall-clock UTC of the current cert&#39;s expiry (null when no cert).
- **lastError**: `String` — Most recent error from verification / issuance, null when clean.

### Tenant

**object**

- **id**: `ID!`
- **name**: `String!`
- **subdomain**: `String` — Platform-managed tenant DNS label. When set and the tenant alias has issued TLS, playback uses foghorn.&lt;subdomain&gt;.cdn.&lt;root&gt; instead of the global Foghorn host.
- **cluster**: `String`
- **createdAt**: `Time!` ([Time](/builders/api-schema/shared/#time))
- **customDomain**: `String` — BYO domain configured for this tenant. Null when the tenant has not opted in.
- **customDomainStatus**: `CustomDomainStatus` ([CustomDomainStatus](/builders/api-schema/account/#customdomainstatus)) — Lifecycle state for the BYO domain, surfacing the CNAMEs the operator must publish for verification + traffic plus any current error/expiry timestamps. Null when no customDomain is configured.
- **monitoringEnabled**: `Boolean!` — Tenant-wide Skipper AI monitoring master switch. Default true.

### UpdateTenantInput

**input_object**

Input for updating tenant settings.

- **name**: `String` — New tenant name.
- **settings**: `JSON` ([JSON](/builders/api-schema/shared/#json)) — Custom settings JSON. Supports primaryClusterId, subdomain, customDomain, and deploymentModel.
- **customDomain**: `String` — BYO domain. Empty string clears it; null leaves it unchanged. Navigator picks up the change on the next reconciler tick and starts/teardowns the verification + cert lifecycle accordingly.
- **monitoringEnabled**: `Boolean` — Tenant-wide Skipper AI monitoring master switch. null leaves it unchanged.

### User

**object**

- **id**: `ID!`
- **email**: `String` — User&#39;s email address. Null for wallet-only accounts.
- **name**: `String`
- **role**: `String!`
- **createdAt**: `Time!` ([Time](/builders/api-schema/shared/#time))
- **wallets**: `[WalletIdentity!]!` ([WalletIdentity](/builders/api-schema/account/#walletidentity)) — Linked wallet addresses for this user.

### WalletIdentity

**object**

A linked cryptocurrency wallet for authentication. Users can link multiple wallets across different chains.

- **id**: `ID!` — Unique identifier for this wallet link.
- **address**: `String!` — The wallet address (chain-specific format, e.g. 0x... for Ethereum).
- **createdAt**: `Time!` ([Time](/builders/api-schema/shared/#time)) — When this wallet was linked.
- **lastAuthAt**: `Time` ([Time](/builders/api-schema/shared/#time)) — When this wallet was last used for authentication.

### WalletLoginInput

**input_object**

Input for wallet-based authentication. The signature proves ownership of the wallet address.

- **address**: `String!` — Ethereum address (0x-prefixed, 40 hex characters).
- **message**: `String!` — Message that was signed, including timestamp and nonce for replay protection.
- **signature**: `String!` — EIP-191 personal_sign signature (0x-prefixed, 65 bytes hex).

### WalletLoginPayload

**object**

Successful wallet login response containing JWT and user info.

- **token**: `String!` — JWT access token for API authentication.
- **user**: `User!` ([User](/builders/api-schema/account/#user)) — The authenticated user.
- **expiresAt**: `Time!` ([Time](/builders/api-schema/shared/#time)) — When the token expires.
- **isNewAccount**: `Boolean!` — True if this was a new account created by the login.
