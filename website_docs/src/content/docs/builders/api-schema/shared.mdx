### Clip

**object**

A video clip extracted from a live stream&#39;s DVR buffer. Clips are created from recorded stream segments and stored for playback.

Implements [Node](/builders/api-schema/shared/#node).

- **id**: `ID!` — Global unique identifier for Relay compatibility.
- **clipHash**: `String!` — Internal clip hash for storage and playback.
- **playbackId**: `String!` — Public playback identifier for generating playback URLs.
- **streamId**: `ID!` — Stream this clip was created from.
- **sourceStreamId**: `String!` — Stable UUID of the source stream this clip was created from.
- **stream**: `Stream` ([Stream](/builders/api-schema/shared/#stream))
- **title**: `String!` — Display title for the clip.
- **description**: `String` — Optional description of clip content.
- **startTime**: `Int!` — Resolved start time (Unix seconds).
- **duration**: `Int!` — Clip duration in seconds.
- **nodeId**: `String` — Node that processed this clip.
- **storagePath**: `String` — Storage path on the processing node.
- **sizeBytes**: `Float` — File size in bytes.
- **status**: `String!` — Processing status (queued, processing, ready, failed).
- **createdAt**: `Time` ([Time](/builders/api-schema/shared/#time)) — When the clip was requested.
- **updatedAt**: `Time` ([Time](/builders/api-schema/shared/#time)) — When the clip was last updated.
- **clipMode**: `String` — Clip creation mode (ABSOLUTE, RELATIVE, DURATION, CLIP_NOW).
- **requestedParams**: `JSON` ([JSON](/builders/api-schema/shared/#json)) — Original request parameters for audit/display.
- **storageLocation**: `String` — Storage backend (local, s3).
- **syncStatus**: `String` — Current S3 sync state (pending, in_progress, synced, failed, lost_local).
- **hasLocalCopy**: `Boolean` — Present full local node copy (origin or cache): true when at least one node holds a complete local copy, false when none remain (playback via read-through relay from S3). Null when the placement overlay (Periscope) is unavailable — unknown, not &#39;no local copy&#39;. Durable S3-only state is derived by consumers as isSynced &amp;&amp; hasLocalCopy == false.
- **isSynced**: `Boolean` — True when S3 has an authoritative copy.
- **isFinalized**: `Boolean` — True when the S3 copy includes the Mist .dtsh index.
- **expiresAt**: `Time` ([Time](/builders/api-schema/shared/#time)) — When the clip will be auto-deleted.
- **isExpired**: `Boolean!` — Whether the clip has passed its retention date (expiresAt &lt; now).
- **playbackPolicy**: `PlaybackPolicy` ([PlaybackPolicy](/builders/api-schema/shared/#playbackpolicy)) — Playback access policy snapshotted at clip creation. null/PUBLIC means anyone with the playbackId can watch. Independent from the source stream&#39;s policy after creation — flipping the source stream&#39;s policy does not affect already-shared clip URLs.
- **thumbnailAssets**: `ThumbnailAssets` ([ThumbnailAssets](/builders/api-schema/shared/#thumbnailassets)) — Server-resolved Chandler URLs for the clip&#39;s poster and sprite thumbnails. Null until Foghorn confirms the thumbnail upload.
- **effectiveRetention**: `EffectiveRetention` ([EffectiveRetention](/builders/api-schema/shared/#effectiveretention)) — Resolved retention horizon with the source of the decision (per-asset override → per-stream override → tenant default → tier entitlement). Null when retention_until is unset (infinite).
- **storageCost**: `StorageCostProjection` ([StorageCostProjection](/builders/api-schema/shared/#storagecostprojection)) — Marginal storage cost for this clip on the tenant&#39;s tier. Null when the tenant has no storage meter (self-hosted, fully tenant-private cluster). Computed from sizeBytes in GiB × unit_price_per_gb_hour × hours_held.

### ConnectionInput

**input_object**

Standard cursor-based pagination input for all connections. Follows the Relay Connection specification for consistent pagination. ## Forward Pagination Use `first` and `after` to paginate forward: ```graphql streamsConnection(page: &#123; first: 10, after: &#34;cursor...&#34; &#125;) ``` ## Backward Pagination Use `last` and `before` to paginate backward: ```graphql streamsConnection(page: &#123; last: 10, before: &#34;cursor...&#34; &#125;) ```

- **first**: `Int` — Number of items to fetch (forward pagination). Default: 50, Max: 500.
- **after**: `String` — Cursor to start fetching after (forward pagination).
- **last**: `Int` — Number of items to fetch (backward pagination).
- **before**: `String` — Cursor to start fetching before (backward pagination).

### DVRChapterMode

**enum**

DVR historical chapter mode. Determines how chapter (startMs, endMs) ranges are produced for finalized replay artifacts. Configured at the Stream level via updateStream and snapshotted onto the DVR artifact at StartDVR. UTC-only — civil-time chapters resolve at the edge.

- `WINDOW_SIZED` — Sequential fixed-length chapters of size tier.MaxWindowSeconds since the recording&#39;s start.
- `FIXED_INTERVAL` — UTC-only intervalSeconds buckets, anchored at unix epoch 0.
- `NONE` — Rolling DVR only: recording still runs, but no historical chapter artifacts are produced.

### EffectiveRetention

**object**

Resolved retention horizon for a single asset (DVR, clip, or VOD). Embedded on Clip, DVRRequest, and VodAsset.

- **retentionDays**: `Int!` — Days from now until the artifact is scheduled for deletion. 0 = no auto-expire (retentionUntil is null).
- **retentionUntil**: `Time` ([Time](/builders/api-schema/shared/#time)) — Scheduled deletion timestamp. Null when the artifact has no horizon (kept forever).
- **source**: `RetentionSource!` ([RetentionSource](/builders/api-schema/shared/#retentionsource))

### PlaybackJwtClaimRequirement

**object**

One required-claim constraint, JSON-encoded for type-flexible matching.

### PlaybackJwtPolicy

**object**

JWT-gated playback policy. The viewer attaches a JWT minted with one of the allowed signing keys; FrameWorks verifies signature, alg=ES256, exp/iat/nbf, and any required audience / claim constraints.

- **allowedKids**: `[String!]!` — Allowed signing key IDs. Empty = any active tenant key.
- **requiredAudience**: `[String!]!` — If set, the viewer JWT&#39;s `aud` claim must contain at least one of these.
- **requiredClaimsJson**: `[PlaybackJwtClaimRequirement!]!` ([PlaybackJwtClaimRequirement](/builders/api-schema/shared/#playbackjwtclaimrequirement)) — Required claim constraints. Each value is the JSON-encoded representation of the expected claim value (so callers can require strings, numbers, booleans, or arrays consistently). Empty = no claim check.

### PlaybackPolicy

**object**

Per-playback-object access policy. Foghorn reads this in the USER_NEW trigger handler; the requiresAuth marker (on the playback object itself) gates whether the full policy is fetched at all.

- **type**: `PlaybackPolicyType!` ([PlaybackPolicyType](/builders/api-schema/shared/#playbackpolicytype))
- **jwt**: `PlaybackJwtPolicy` ([PlaybackJwtPolicy](/builders/api-schema/shared/#playbackjwtpolicy)) — JWT-policy details, populated when type == JWT.
- **webhook**: `PlaybackWebhookPolicy` ([PlaybackWebhookPolicy](/builders/api-schema/shared/#playbackwebhookpolicy)) — Webhook-policy details, populated when type == WEBHOOK. Secret is masked.

### PlaybackPolicyType

**enum**

- `PUBLIC`

### PlaybackWebhookPolicy

**object**

Webhook-callback playback policy. On every viewer connect, FrameWorks POSTs to the URL with an HMAC-signed body and reads allow/deny from the response. The secret is write-only on input and is never returned by queries.

- **url**: `String!`
- **timeoutMs**: `Int!` — Outbound POST timeout in milliseconds. Capped server-side at 10000.
- **secretMasked**: `String!` — Always &#39;redacted&#39; on read; the actual secret is fieldcrypt-encrypted at rest.
