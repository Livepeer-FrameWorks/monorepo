## Analytics

**object**

Unified analytics surface for all platform metrics. Organized into logical domains: usage, health, lifecycle, and infrastructure.

- **overview**: `PlatformOverview` ([PlatformOverview](/builders/api-schema/analytics-types-a-r/#platformoverview)) — Platform-wide overview metrics for the given time range.
  - `timeRange`: `TimeRangeInput` ([TimeRangeInput](/builders/api-schema/shared/#timerangeinput)) — Time range for the overview.
- **usage**: `AnalyticsUsage!` ([AnalyticsUsage](/builders/api-schema/analytics-types-a-r/#analyticsusage)) — Usage analytics: streaming hours, storage, and processing.
- **health**: `AnalyticsHealth!` ([AnalyticsHealth](/builders/api-schema/analytics-types-a-r/#analyticshealth)) — Health analytics: stream quality, rebuffering, client QoE.
- **lifecycle**: `AnalyticsLifecycle!` ([AnalyticsLifecycle](/builders/api-schema/analytics-types-a-r/#analyticslifecycle)) — Lifecycle analytics: stream events, artifacts, connections.
- **infra**: `AnalyticsInfra!` ([AnalyticsInfra](/builders/api-schema/analytics-types-a-r/#analyticsinfra)) — Infrastructure analytics: routing, node metrics, services.

  - `artifactHash`: `String`
  - `timeRange`: `TimeRangeInput` ([TimeRangeInput](/builders/api-schema/shared/#timerangeinput))
  - `interval`: `String` (default `&#34;1h&#34;`)
  - `noCache`: `Boolean` (default `false`)

Companion to sessionQoeSummary for trend charts. `sessionCount` and `playedHours` per bucket are the denominators for low-sample windows.
  - `streamId`: `ID`
  - `artifactHash`: `String`
  - `timeRange`: `TimeRangeInput` ([TimeRangeInput](/builders/api-schema/shared/#timerangeinput))
  - `interval`: `String` (default `&#34;1h&#34;`)
  - `noCache`: `Boolean` (default `false`)
- **vodRetentionAssets**: `VodRetentionAssetConnection!` ([VodRetentionAssetConnection](/builders/api-schema/analytics-types-s-v/#vodretentionassetconnection)) — VOD assets that have retention data in the window — the picker backing the retention view. Eligibility (VOD content with real reach samples) is owned by analytics; title/playbackId are composed from the catalog by artifactHash.
  - `page`: `ConnectionInput` ([ConnectionInput](/builders/api-schema/shared/#connectioninput))
  - `timeRange`: `TimeRangeInput` ([TimeRangeInput](/builders/api-schema/shared/#timerangeinput))
  - `noCache`: `Boolean` (default `false`)
- **topAssets**: `[TopAssetEntry!]!` ([TopAssetEntry](/builders/api-schema/analytics-types-s-v/#topassetentry)) — Top assets by audience in the window — server-ranked by sessions, across every kind (VOD, clip, DVR, chapter). Backs the &#34;Top Assets&#34; table on the analytics overview. title/playbackId are composed from the catalog by artifactHash.
  - `timeRange`: `TimeRangeInput` ([TimeRangeInput](/builders/api-schema/shared/#timerangeinput))
  - `limit`: `Int` (default `10`)
- **artifactNodeCopies**: `AssetNodeCopies!` ([AssetNodeCopies](/builders/api-schema/analytics-types-a-r/#assetnodecopies)) — Nodes currently holding a transient LOCAL COPY of one artifact (not the durable object-storage copy), from the node-copy telemetry the media plane emits. `role` is `origin` (producer/relay source) or `cache` (synced pull); `isComplete` marks a full local copy. Read-through relay block caches are not represented. Node geo is enriched from the infrastructure registry. `artifactHash` is required. When `truncated` is true the node set was capped and is NOT exhaustive.
  - `artifactHash`: `String!`

## AssetNodeCopies

**object**

A node-copy listing plus whether it was capped at the per-request limit. When `truncated` is true, `copies` is not exhaustive — present the count as a lower bound (e.g. &#34;500+&#34;) or a &#34;results truncated&#34; note, never as an exact total.

- **copies**: `[AssetNodeCopy!]!` ([AssetNodeCopy](/builders/api-schema/analytics-types-a-r/#assetnodecopy))
- **truncated**: `Boolean!`
