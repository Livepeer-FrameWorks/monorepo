## Queries

### Query.conversation

Fetch a single conversation by ID.

```graphql
conversation(
  id: ID!
): Conversation
```

**Returns:** `Conversation` ([Conversation](/builders/api-schema/shared/#conversation))

**Arguments**

- `id`: `ID!` — The conversation ID.

### Query.conversationsConnection

List all support conversations for the current tenant. Conversations are ordered by last activity, most recent first.

| Operation | TypeScript | Go | Python |
| --- | --- | --- | --- |
| GetConversationsConnection | `GetConversationsConnectionDocument` | `GetConversationsConnection` | `get_conversations_connection` |

## Types

### ConversationEdge

**object**

A conversation edge in a connection.

- **node**: `Conversation!` ([Conversation](/builders/api-schema/shared/#conversation)) — The conversation.
- **cursor**: `String!` — Cursor for this edge.

### ConversationsConnection

**object**

Paginated list of conversations.

- **edges**: `[ConversationEdge!]!` ([ConversationEdge](/builders/api-schema/support/#conversationedge)) — List of conversations.
- **pageInfo**: `PageInfo!` ([PageInfo](/builders/api-schema/shared/#pageinfo)) — Pagination information.
- **totalCount**: `Int!` — Total count of conversations.

### CreateConversationInput

**input_object**

Input for creating a new conversation.

- **subject**: `String` — Optional subject line.
- **message**: `String!` — Initial message content (required).
- **pageUrl**: `String` — Optional page URL where conversation was initiated.

### CreateConversationResult

**union**

- Member: [Conversation](/builders/api-schema/shared/#conversation)
- Member: [ValidationError](/builders/api-schema/shared/#validationerror)
- Member: [AuthError](/builders/api-schema/shared/#autherror)

### MessageEdge

**object**

A message edge in a connection.

- **node**: `Message!` ([Message](/builders/api-schema/shared/#message)) — The message.
- **cursor**: `String!` — Cursor for this edge.

### MessagesConnection

**object**

Paginated list of messages.

- **edges**: `[MessageEdge!]!` ([MessageEdge](/builders/api-schema/support/#messageedge)) — List of messages.
- **pageInfo**: `PageInfo!` ([PageInfo](/builders/api-schema/shared/#pageinfo)) — Pagination information.
- **totalCount**: `Int!` — Total count of messages.

### SendMessageInput

**input_object**

Input for sending a message.

- **conversationId**: `ID!` — The conversation ID to send the message to.
- **content**: `String!` — The message content.

### SendMessageResult

**union**

- Member: [Message](/builders/api-schema/shared/#message)
- Member: [ValidationError](/builders/api-schema/shared/#validationerror)
- Member: [NotFoundError](/builders/api-schema/shared/#notfounderror)
- Member: [AuthError](/builders/api-schema/shared/#autherror)
