## Queries

### Query.balanceTransactionsConnection

List balance transactions for the tenant with pagination.

```graphql
balanceTransactionsConnection(
  page: ConnectionInput
  transactionType: String
  timeRange: TimeRangeInput
): BalanceTransactionsConnection!
```

**Returns:** `BalanceTransactionsConnection!` ([BalanceTransactionsConnection](/builders/api-schema/billing-types/#balancetransactionsconnection))

**Arguments**

- `page`: `ConnectionInput` ([ConnectionInput](/builders/api-schema/shared/#connectioninput)) — Pagination options.
- `transactionType`: `String` — Filter by transaction type: topup, usage, refund, adjustment.
- `timeRange`: `TimeRangeInput` ([TimeRangeInput](/builders/api-schema/shared/#timerangeinput)) — Time range to query.

### Mutation.changeBillingTier

Change the postpaid billing tier. Upgrades apply immediately and reconcile cluster access; downgrades are scheduled for the current billing period end so the tenant keeps paid entitlements until the period closes.

```graphql

  tierId: ID!
): ChangeBillingTierResult!
```

**Returns:** `ChangeBillingTierResult!` ([ChangeBillingTierResult](/builders/api-schema/billing-types/#changebillingtierresult))

**Arguments**

- `tierId`: `ID!` — The target billing tier. Must be an active postpaid tier (tier_level &gt;= 1).

### Mutation.createMollieFirstPayment

Create a Mollie first payment to establish a mandate. For iDEAL: User pays via bank → SEPA Direct Debit mandate is created. For card: User enters card → card mandate is created. After successful payment, call createMollieSubscription to start recurring billing.

```graphql
createMollieFirstPayment(
  tierId: ID!
  method: String!
  redirectUrl: String!
): MollieFirstPaymentResult!
```

**Returns:** `MollieFirstPaymentResult!` ([MollieFirstPaymentResult](/builders/api-schema/billing-types/#molliefirstpaymentresult))

**Arguments**

- `tierId`: `ID!` — The billing tier to subscribe to.
- `method`: `String!` — Payment method: &#39;ideal&#39;, &#39;creditcard&#39;, &#39;bancontact&#39;.
- `redirectUrl`: `String!` — URL to redirect to after payment.

**SDK**

| Operation | TypeScript | Go | Python |
| --- | --- | --- | --- |
| CreateMollieFirstPayment | `CreateMollieFirstPaymentDocument` | `CreateMollieFirstPayment` | `create_mollie_first_payment` |

### Mutation.submitX402Payment

Submit an x402 payment payload to settle a 402 response or top up balance. Authenticated members may settle viewer resources; direct top-ups and non-viewer resources require billing management authority on the target tenant.

```graphql
submitX402Payment(
  payment: String!
  resource: String
): SubmitX402PaymentResult!
```

**Returns:** `SubmitX402PaymentResult!` ([SubmitX402PaymentResult](/builders/api-schema/billing-types/#submitx402paymentresult))

**Arguments**

- `payment`: `String!` — Base64-encoded x402 payment payload.
- `resource`: `String` — Optional resource being paid for. Viewer resources credit their resolved owner tenant; omission defaults to the authenticated tenant.

**SDK**

| Operation | TypeScript | Go | Python |
| --- | --- | --- | --- |
| SubmitX402Payment | `SubmitX402PaymentDocument` | `SubmitX402Payment` | `submit_x_402_payment` |
