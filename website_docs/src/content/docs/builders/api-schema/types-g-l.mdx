## InfrastructureNode

**object**

An infrastructure node in a cluster (edge server, origin, transcoder). Nodes handle stream ingest, transcoding, and delivery to viewers.

Implements [Node](/builders/api-schema/types-m-r/#node).

- **id**: `ID!` — Global unique identifier for Relay compatibility.
- **nodeId**: `String!` — Internal node identifier (UUID).
- **clusterId**: `String!` — Cluster this node belongs to.
- **nodeName**: `String!` — Human-readable node name.
- **nodeType**: `String!` — Node role (edge, origin, transcoder, hybrid).
- **internalIp**: `String` — Private network IP address.
- **externalIp**: `String` — Public IP address for external access.
- **wireguardIp**: `String` — WireGuard mesh network IP.
- **wireguardPublicKey**: `String` — WireGuard public key for mesh peering.
- **region**: `String` — Geographic region (us-east, eu-west, etc.).
- **latitude**: `Float` — GPS latitude.
- **longitude**: `Float` — GPS longitude.
- **availabilityZone**: `String` — Availability zone within region.
- **cpuCores**: `Int` — Number of CPU cores.
- **memoryGb**: `Int` — Memory in gigabytes.
- **diskGb**: `Int` — Disk storage in gigabytes.
- **lastHeartbeat**: `Time` ([Time](/builders/api-schema/types-s-z/#time)) — Last heartbeat timestamp from node agent.
- **tags**: `JSON` ([JSON](/builders/api-schema/types-g-l/#json)) — Custom tags for node organization.
- **metadata**: `JSON` ([JSON](/builders/api-schema/types-g-l/#json)) — Additional node metadata.
- **createdAt**: `Time` ([Time](/builders/api-schema/types-s-z/#time)) — When the node was registered.
- **updatedAt**: `Time` ([Time](/builders/api-schema/types-s-z/#time)) — When the node was last updated.
- **metricsConnection**: `NodeMetricsConnection!` ([NodeMetricsConnection](/builders/api-schema/types-m-r/#nodemetricsconnection)) — Paginated time-series metrics for this node.
  - `page`: `ConnectionInput` ([ConnectionInput](/builders/api-schema/types-a-f/#connectioninput))
  - `timeRange`: `TimeRangeInput` ([TimeRangeInput](/builders/api-schema/types-s-z/#timerangeinput))
- **metrics1hConnection**: `NodeMetrics1hConnection!` ([NodeMetrics1hConnection](/builders/api-schema/types-m-r/#nodemetrics1hconnection)) — Hourly aggregated metrics for this node.
  - `page`: `ConnectionInput` ([ConnectionInput](/builders/api-schema/types-a-f/#connectioninput))
  - `timeRange`: `TimeRangeInput` ([TimeRangeInput](/builders/api-schema/types-s-z/#timerangeinput))
- **liveState**: `LiveNode` ([LiveNode](/builders/api-schema/types-g-l/#livenode)) — Real-time state from the analytics data plane.
- **effectiveMode**: `NodeOperationalMode!` ([NodeOperationalMode](/builders/api-schema/types-m-r/#nodeoperationalmode)) — Current operational mode (normal / draining / maintenance). Read from Foghorn&#39;s per-node heartbeat. Changes via setNodeMode.
- **routingImpactPreview**: `RoutingImpactPreview!` ([RoutingImpactPreview](/builders/api-schema/types-m-r/#routingimpactpreview)) — Current traffic on this node. Operators use these counts to understand how much live traffic is affected before draining or entering maintenance. Counts come from Foghorn&#39;s GetNodeHealth.

## Invoice

**object**

A billing invoice for a subscription period. Includes base subscription and metered usage charges. Amounts are computed in EUR; a finalized invoice is presented and charged in the tenant&#39;s presentment currency at the ECB rate of its finalization date.

- **id**: `ID!` — Unique invoice identifier.
- **amount**: `Money!` ([Money](/builders/api-schema/types-m-r/#money)) — Total amount due in EUR (after credits applied).
- **baseAmount**: `Money!` ([Money](/builders/api-schema/types-m-r/#money)) — Base subscription amount in EUR.
- **meteredAmount**: `Money!` ([Money](/builders/api-schema/types-m-r/#money)) — Metered usage charges in EUR (net; 0 while usage is waived during beta).
- **grossMeteredAmount**: `Money!` ([Money](/builders/api-schema/types-m-r/#money)) — Unwaived metered total — what usage would have cost. Equals meteredAmount when usage is not waived; the would-have-cost figure when it is.
- **prepaidCreditApplied**: `Money!` ([Money](/builders/api-schema/types-m-r/#money)) — Prepaid balance credit applied to this invoice, in EUR.
- **currency**: `Currency!` ([Currency](/builders/api-schema/types-a-f/#currency)) — Currency of the amounts above, EUR.
- **presentmentAmountCents**: `Int` — Total charged, in cents of `presentmentCurrency`. Null until the invoice is finalized.
- **presentmentCurrency**: `String` — Currency the invoice is presented and charged in (EUR, USD, GBP). Empty until the invoice is finalized.
- **presentmentUnitsPerEur**: `String` — Units of `presentmentCurrency` one euro buys at finalization, as a decimal string. Empty until the invoice is finalized.
- **presentmentReferenceDate**: `String` — ECB reference date of the presentment rate (YYYY-MM-DD). Empty until the invoice is finalized.
- **finalizedAt**: `Time` ([Time](/builders/api-schema/types-s-z/#time)) — When the invoice was finalized and its presentment amount fixed.
- **status**: `InvoiceStatus!` ([InvoiceStatus](/builders/api-schema/types-g-l/#invoicestatus)) — Invoice status (draft, open, paid, void).
- **dueDate**: `Time!` ([Time](/builders/api-schema/types-s-z/#time)) — Payment due date.
- **paidAt**: `Time` ([Time](/builders/api-schema/types-s-z/#time)) — When payment was received.
- **createdAt**: `Time!` ([Time](/builders/api-schema/types-s-z/#time)) — When the invoice was created.
- **updatedAt**: `Time!` ([Time](/builders/api-schema/types-s-z/#time)) — When the invoice was last updated.
- **periodStart**: `Time` ([Time](/builders/api-schema/types-s-z/#time)) — Billing period start date.
- **periodEnd**: `Time` ([Time](/builders/api-schema/types-s-z/#time)) — Billing period end date.
- **usageDetails**: `JSON` ([JSON](/builders/api-schema/types-g-l/#json)) — Detailed usage breakdown (JSON).
- **lineItems**: `[LineItem!]!` ([LineItem](/builders/api-schema/types-g-l/#lineitem)) — Individual line items on the invoice.

## LineItem

**object**

A single line item on an invoice or usage preview, produced by the rating engine. Decimal quantities are strings to preserve precision.

- **lineKey**: `String!` — Stable identity: &#39;base_subscription&#39;, &#39;meter:&lt;name&gt;:&lt;cluster_id&gt;:&lt;yyyymm&gt;&#39;.
- **meter**: `String!` — Meter name; empty for base_subscription.
- **description**: `String!` — Description of the charge.
- **quantity**: `String!` — Total quantity used (decimal as string).
- **includedQuantity**: `String!` — Free quantity (decimal as string).
- **billableQuantity**: `String!` — Billable quantity (decimal as string).
- **unitPrice**: `String!` — Price per unit (decimal as string).
- **total**: `String!` — Total for this line item (= billableQuantity * unitPrice), decimal as string.
- **currency**: `String!` — Currency (ISO 4217).
- **clusterId**: `String` — Cluster id this line was attributed to; null for tenant-scoped lines (base_subscription).
- **clusterName**: `String` — Display name of the cluster, joined from Quartermaster at read time. Null when clusterId is null.
- **clusterKind**: `String` — platform_official &#124; tenant_private &#124; third_party_marketplace; null when clusterId is null.
- **pricingSource**: `String!` — Why the line was priced as it was: tier, cluster_metered, cluster_monthly, cluster_custom, free_unmetered, self_hosted, included_subscription.
- **pricingLabel**: `String!` — Human-readable label of pricingSource (e.g. &#39;Self-hosted (no charge)&#39;, &#39;Marketplace metered&#39;). Empty when not populated by the gateway.
- **unit**: `String!` — Canonical quantity unit.
- **dimensions**: `JSON!` ([JSON](/builders/api-schema/types-g-l/#json)) — Bounded pricing dimensions such as codec, rendition, backend, or model.
