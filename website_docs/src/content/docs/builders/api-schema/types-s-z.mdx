## SigningKey

**object**

A customer-managed signing key for issuing viewer playback JWTs. The private key is returned exactly once at creation time (in CreateSigningKeySuccess); FrameWorks stores only the public key. Up to 10 active keys per tenant.

Implements [Node](/builders/api-schema/types-m-r/#node).

- **id**: `ID!`
- **kid**: `String!` — Short ID embedded in JWT header (`kid`) for fast key lookup.
- **name**: `String!` — Customer-supplied label.
- **algorithm**: `SigningKeyAlgorithm!` ([SigningKeyAlgorithm](/builders/api-schema/types-s-z/#signingkeyalgorithm)) — Algorithm — ES256 only for v1.
- **publicKeyPem**: `String!` — Public key in PEM format. The private key is never stored.
- **status**: `SigningKeyStatus!` ([SigningKeyStatus](/builders/api-schema/types-s-z/#signingkeystatus)) — Lifecycle status.
- **createdAt**: `Time!` ([Time](/builders/api-schema/types-s-z/#time))
- **lastUsedAt**: `Time` ([Time](/builders/api-schema/types-s-z/#time)) — Last time a JWT signed by this key successfully verified at playback.
- **revokedAt**: `Time` ([Time](/builders/api-schema/types-s-z/#time)) — When the key was revoked (null if active).

Algorithm used to sign viewer playback JWTs. ES256 only for v1.

## SourceLocationInput

**input_object**

Replaces the stream&#39;s own ingest restriction. Private and multicast pull sources require RESTRICTED with clusters that allow private pull sources.

- **mode**: `SourceLocationMode!` ([SourceLocationMode](/builders/api-schema/types-s-z/#sourcelocationmode)) — ANY or RESTRICTED. CUSTOM is rejected.
- **clusters**: `[SourceLocationClusterInput!]!` ([SourceLocationClusterInput](/builders/api-schema/types-s-z/#sourcelocationclusterinput)) — Required and non-empty for RESTRICTED; must be empty for ANY.
- **avoidNodeIds**: `[ID!]!` — Nodes the source must never run on. Only nodes of clusters the tenant owns are accepted.

## SourceLocationMode

**enum**

Where a stream&#39;s source may be ingested. It is a summary of the stream&#39;s own ingest placement rules.

- `ANY` — No stream-level restriction; FrameWorks chooses among the tenant&#39;s entitled clusters.
- `RESTRICTED` — Only the listed clusters, optionally narrowed to specific nodes and excluding avoided nodes.
- `CUSTOM` — The stream&#39;s own ingest rules contain constraints this summary cannot express. Read-only here; edit them in the stream&#39;s placement rules.

## Stream

**object**

A live stream configuration with real-time operational metrics. Streams are the core entity for broadcasting and viewing live content.

Implements [Node](/builders/api-schema/types-m-r/#node).

## TestPlaybackAccessInput

**input_object**

Inputs for testPlaybackAccess. Exactly one of playbackId / internalName must be set (the server rejects both-set and neither-set). viewerToken is required for JWT policies and is forwarded to the webhook payload for webhook policies. fireWebhook gates a real outbound HTTPS call to the customer URL. That call uses the same SSRF-hardened evaluator path as live viewer admission, and customer endpoints may log, rate-limit, or trigger side effects from the test request. When playbackId is supplied, the server resolves the canonical internalName before invoking the evaluator so webhook payloads carry the same streamName the live USER_NEW path would.

- **playbackId**: `String`
- **internalName**: `String`
- **viewerToken**: `String` — JWT to test (required for type=jwt; passed through in the webhook payload for type=webhook).
- **viewerIp**: `String`
- **requestUrl**: `String`
- **connector**: `String`
- **sessionId**: `String`
- **fireWebhook**: `Boolean` — Webhook policies only: when true, Foghorn will POST to the configured customer URL with an HMAC-signed payload (same path the live evaluator uses). When false, the evaluator returns reason=&#34;webhook-test-skipped&#34; without making the call so operators can inspect the resolved policy without side effects.

## VodAsset

**object**

A Video-on-Demand asset uploaded by the tenant. VOD assets can be played back using the playbackId in playback URLs.

Implements [Node](/builders/api-schema/types-m-r/#node).

- **id**: `ID!` — Global unique identifier for Relay compatibility.
- **artifactHash**: `String!` — Internal hash used for playback URL resolution.
- **playbackId**: `String!` — Public playback identifier for generating playback URLs.
- **streamId**: `String` — Source stream UUID for stream-derived VOD artifacts such as DVR chapters.
- **originType**: `String` — Registry origin kind. Null/user_upload for ordinary uploads; dvr_chapter for finalized DVR chapters.
- **originId**: `String` — Origin entity id, such as DVR chapter_id when originType=dvr_chapter.
- **title**: `String` — Optional display title for the asset.
- **description**: `String` — Optional description of the asset content.
- **filename**: `String` — Original filename when uploaded.
- **status**: `VodAssetStatus!` ([VodAssetStatus](/builders/api-schema/types-s-z/#vodassetstatus)) — Current processing/storage status of the asset.
- **storageLocation**: `String!` — Where the asset is stored (s3, local, freezing).
- **syncStatus**: `String` — Current S3 sync state (pending, in_progress, synced, failed, lost_local).
- **hasLocalCopy**: `Boolean` — Present full local node copy (origin or cache): true when at least one node holds a complete local copy, false when none remain (playback via Helmsman&#39;s read-through relay from S3). Null when the placement overlay (Periscope) is unavailable — unknown, not &#39;no local copy&#39;. Durable S3-only state is derived by consumers as isSynced &amp;&amp; hasLocalCopy == false.
- **isSynced**: `Boolean!` — True when S3 has an authoritative copy.
- **isFinalized**: `Boolean!` — True when the S3 copy includes the Mist .dtsh index.
- **sizeBytes**: `Float` — File size in bytes (available after validation).
- **durationMs**: `Int` — Video duration in milliseconds.
- **resolution**: `String` — Video resolution (e.g., &#39;1920x1080&#39;).
- **videoCodec**: `String` — Video codec (h264, h265, vp9, av1).
- **audioCodec**: `String` — Audio codec (aac, opus).
- **bitrateKbps**: `Int` — Average bitrate in kbps.
- **createdAt**: `Time!` ([Time](/builders/api-schema/types-s-z/#time)) — When the asset was created/uploaded.
- **updatedAt**: `Time!` ([Time](/builders/api-schema/types-s-z/#time)) — When the asset was last modified.
- **expiresAt**: `Time` ([Time](/builders/api-schema/types-s-z/#time)) — Optional expiration time for auto-deletion.
- **errorMessage**: `String` — Error message if processing failed.
- **playbackPolicy**: `PlaybackPolicy` ([PlaybackPolicy](/builders/api-schema/types-m-r/#playbackpolicy)) — Playback access policy. null/PUBLIC = anyone with the playbackId can watch.
- **thumbnailAssets**: `ThumbnailAssets` ([ThumbnailAssets](/builders/api-schema/types-s-z/#thumbnailassets)) — Server-resolved Chandler URLs for the VOD&#39;s poster and sprite thumbnails. Null until Foghorn confirms the thumbnail upload.
- **effectiveRetention**: `EffectiveRetention` ([EffectiveRetention](/builders/api-schema/types-a-f/#effectiveretention)) — Resolved retention horizon with the source of the decision (per-asset override → per-stream override → tenant default → tier entitlement). Null while the asset&#39;s retention_until column is unset (infinite).
- **storageCost**: `StorageCostProjection` ([StorageCostProjection](/builders/api-schema/types-s-z/#storagecostprojection)) — Marginal storage cost for this asset on the tenant&#39;s tier. Null when the tenant has no storage meter (self-hosted, fully tenant-private cluster). Computed from sizeBytes in GiB × unit_price_per_gb_hour × hours_held.
