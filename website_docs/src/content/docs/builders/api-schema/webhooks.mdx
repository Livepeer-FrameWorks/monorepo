Webhook endpoints, deliveries, replays, and event types.

Types used by more than one domain are on [Shared types](/builders/api-schema/shared/).

## Queries

### Query.webhookDeliveriesConnection

List webhook deliveries newest first, optionally filtered. Only forward pagination is supported.

```graphql
webhookDeliveriesConnection(
  endpointId: ID
  statuses: [WebhookDeliveryStatus!]
  eventType: String
  eventId: ID
  createdAfter: Time
  createdBefore: Time
  page: ConnectionInput
): WebhookDeliveriesConnection!
```

**Returns:** `WebhookDeliveriesConnection!` ([WebhookDeliveriesConnection](/builders/api-schema/webhooks/#webhookdeliveriesconnection))

**Arguments**

- `endpointId`: `ID` — Only deliveries to this endpoint.
- `statuses`: `[WebhookDeliveryStatus!]` ([WebhookDeliveryStatus](/builders/api-schema/webhooks/#webhookdeliverystatus)) — Only deliveries in these statuses.
- `eventType`: `String` — Only deliveries of this event type, e.g. &#34;stream.live&#34;.
- `eventId`: `ID` — Only deliveries of this event.
- `createdAfter`: `Time` ([Time](/builders/api-schema/shared/#time)) — Only deliveries created at or after this time.
- `createdBefore`: `Time` ([Time](/builders/api-schema/shared/#time)) — Only deliveries created before this time.
- `page`: `ConnectionInput` ([ConnectionInput](/builders/api-schema/shared/#connectioninput))

### WebhookDelivery

**object**

One delivery of one event to one endpoint, or a test delivery.

- **id**: `ID!` — Delivery ID. A replay keeps it.
- **endpointId**: `ID!`
- **eventId**: `ID` — The event ID, sent as webhook-id and as the body&#39;s id. Null for test deliveries.
- **eventType**: `String!`
- **kind**: `WebhookDeliveryKind!` ([WebhookDeliveryKind](/builders/api-schema/webhooks/#webhookdeliverykind))
- **status**: `WebhookDeliveryStatus!` ([WebhookDeliveryStatus](/builders/api-schema/webhooks/#webhookdeliverystatus))
- **attempts**: `Int!` — Attempts since the delivery was created or last replayed.
- **nextAttemptAt**: `Time` ([Time](/builders/api-schema/shared/#time)) — When the next attempt is due; null unless pending.
- **lastStatusCode**: `Int!` — HTTP status of the last attempt; 0 when no response arrived.
- **lastErrorClass**: `String!` — Failure class of the last attempt: http_status, redirect, timeout, connection, tls, dns, or blocked_destination; internal when FrameWorks could not sign or render the delivery; empty after a success.
- **deliveredAt**: `Time` ([Time](/builders/api-schema/shared/#time))
- **replayCount**: `Int!`
- **lastReplayedAt**: `Time` ([Time](/builders/api-schema/shared/#time))
- **createdAt**: `Time!` ([Time](/builders/api-schema/shared/#time))
- **updatedAt**: `Time!` ([Time](/builders/api-schema/shared/#time))
- **attemptHistory**: `[WebhookDeliveryAttempt!]!` ([WebhookDeliveryAttempt](/builders/api-schema/webhooks/#webhookdeliveryattempt)) — Every HTTP attempt, oldest first, including attempts before the last replay.

### WebhookDeliveryStatus

**enum**

- `PENDING` — Waiting for the first attempt or a retry.
- `SUCCEEDED`
- `FAILED` — Every attempt of the retry schedule (about 3 days) failed, or a test delivery failed.
- `SKIPPED` — The endpoint was disabled before the delivery succeeded.

### WebhookEndpoint

**object**

An outbound webhook endpoint. FrameWorks POSTs the tenant&#39;s public events of the subscribed types to its URL, signed with the Standard Webhooks scheme (webhook-id, webhook-timestamp, webhook-signature headers).

- **id**: `ID!` — Endpoint ID.
- **url**: `String!` — The https URL deliveries are sent to.
- **description**: `String!` — Free-text description.
- **eventTypes**: `[String!]!` — Public event types the endpoint receives; &#34;*&#34; receives every type.
- **apiVersion**: `String!` — Public event package version the payloads are rendered with, e.g. &#34;v1&#34;.
- **status**: `WebhookEndpointStatus!` ([WebhookEndpointStatus](/builders/api-schema/webhooks/#webhookendpointstatus))
- **disabledReason**: `WebhookEndpointDisabledReason` ([WebhookEndpointDisabledReason](/builders/api-schema/webhooks/#webhookendpointdisabledreason)) — Why the endpoint is disabled; null while enabled.
- **disabledAt**: `Time` ([Time](/builders/api-schema/shared/#time)) — When the endpoint was disabled; null while enabled.
- **consecutiveFailures**: `Int!` — Failed attempts since the last successful delivery.
- **failingSince**: `Time` ([Time](/builders/api-schema/shared/#time)) — First failed attempt since the last successful delivery.
- **lastSuccessAt**: `Time` ([Time](/builders/api-schema/shared/#time))
- **lastFailureAt**: `Time` ([Time](/builders/api-schema/shared/#time))
- **previousSecretExpiresAt**: `Time` ([Time](/builders/api-schema/shared/#time)) — Until when the previous signing secret still signs deliveries; null when there is none.
- **createdAt**: `Time!` ([Time](/builders/api-schema/shared/#time))
- **updatedAt**: `Time!` ([Time](/builders/api-schema/shared/#time))

### WebhookEndpointDisabledReason

**enum**

- `USER` — Disabled through the API or dashboard.
- `FAILING` — Disabled automatically after at least 20 consecutive failed attempts over at least 5 days without a success.
