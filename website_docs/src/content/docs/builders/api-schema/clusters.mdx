### Mutation.openMistAdminSession

Open the MistServer admin UI on a specific edge node. Returns a short-TTL session token plus the per-edge POST URL the webapp must submit the token to (NOT a query parameter, so the token doesn&#39;t leak via referrers / URL history / access logs). On success the browser sets a `fw_mist_admin` cookie scoped to /_mist and is redirected to /_mist/. Authority is infrastructure ownership, not subscriber access: Mist admin access is effectively shell on the edge box, so only owner/admin users in the cluster owner tenant can open it. Holders of the platform_operator grant are allowed as break-glass. Anything else returns AuthError without exposing whether the node exists.

```graphql
openMistAdminSession(
  input: OpenMistAdminSessionInput!
): OpenMistAdminSessionResult!
```
