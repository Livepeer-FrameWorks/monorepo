## dvrChapter

Retrieve a single DVR chapter, including its finalized playbackId. Chapters are produced by the finalization queue as canonical .mkv VOD artifacts. Historical chapter mode is configured at the Stream level (Stream.dvrChapterMode) and snapshotted at StartDVR. Modes: - WINDOW_SIZED: sequential fixed-length chapters of size tier.MaxWindowSeconds since the recording&#39;s start. - FIXED_INTERVAL: UTC-only buckets of intervalSeconds, anchored at unix epoch 0.

**Returns:** `DVRChapter` ([DVRChapter](/builders/api-schema/types-a-f/#dvrchapter))

**Typed SDK document:** `GetDVRChapter`

**Arguments**

- `dvrId`: `ID!` — DVR recording identifier — accepts either DVRRequest.id (UUID) or DVRRequest.dvrHash.
- `mode`: `DVRChapterMode` ([DVRChapterMode](/builders/api-schema/types-a-f/#dvrchaptermode)) — Historical chapter mode; null defaults to the recording&#39;s policy snapshot.
- `intervalSeconds`: `Int` — Required for FIXED_INTERVAL mode.
- `startMs`: `Float!` — UTC epoch milliseconds (start of range).
- `endMs`: `Float!` — UTC epoch milliseconds (end of range, exclusive).

## dvrChapters

List chapters for a DVR recording. Paginated for unbounded artifact lifetime — default 200 per page, max 1000.

**Returns:** `DVRChaptersPage` ([DVRChaptersPage](/builders/api-schema/types-a-f/#dvrchapterspage))

**Typed SDK document:** `ListDVRChapters`

**Arguments**

- `dvrId`: `ID!` — DVR recording identifier — accepts either DVRRequest.id (UUID) or DVRRequest.dvrHash.
- `mode`: `DVRChapterMode` ([DVRChapterMode](/builders/api-schema/types-a-f/#dvrchaptermode)) — Restrict to chapters of this mode; null = all.
- `intervalSeconds`: `Int` — Required when filtering by FIXED_INTERVAL.
- `rangeStartMs`: `Float` — UTC epoch ms lower bound; 0 = no lower bound.
- `rangeEndMs`: `Float` — UTC epoch ms upper bound; 0 = no upper bound.
- `pageSize`: `Int` — Default 200. Max 1000.
- `pageToken`: `String` — Keyset cursor from a previous page&#39;s nextPageToken.

## usageAggregates

Get aggregated usage data grouped by time interval.

**Returns:** `[UsageAggregate!]!` ([UsageAggregate](/builders/api-schema/types-s-z/#usageaggregate))

**Typed SDK document:** `GetUsageAggregates`

**Arguments**

- `timeRange`: `TimeRangeInput!` ([TimeRangeInput](/builders/api-schema/types-s-z/#timerangeinput)) — Time range to query (required).
- `granularity`: `String` (default `&#34;daily&#34;`) — Aggregation granularity: hourly, daily, or monthly.
- `usageTypes`: `[String!]` — Filter by usage types.

## webhookDeliveriesConnection

List webhook deliveries newest first, optionally filtered. Only forward pagination is supported.

**Returns:** `WebhookDeliveriesConnection!` ([WebhookDeliveriesConnection](/builders/api-schema/types-s-z/#webhookdeliveriesconnection))

**SDK:** Raw GraphQL only

**Arguments**

- `endpointId`: `ID` — Only deliveries to this endpoint.
- `statuses`: `[WebhookDeliveryStatus!]` ([WebhookDeliveryStatus](/builders/api-schema/types-s-z/#webhookdeliverystatus)) — Only deliveries in these statuses.
- `eventType`: `String` — Only deliveries of this event type, e.g. &#34;stream.live&#34;.
- `eventId`: `ID` — Only deliveries of this event.
- `createdAfter`: `Time` ([Time](/builders/api-schema/types-s-z/#time)) — Only deliveries created at or after this time.
- `createdBefore`: `Time` ([Time](/builders/api-schema/types-s-z/#time)) — Only deliveries created before this time.
- `page`: `ConnectionInput` ([ConnectionInput](/builders/api-schema/types-a-f/#connectioninput))
