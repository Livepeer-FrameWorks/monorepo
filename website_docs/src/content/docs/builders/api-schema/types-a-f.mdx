## Analytics

**object**

Unified analytics surface for all platform metrics. Organized into logical domains: usage, health, lifecycle, and infrastructure.

- **overview**: `PlatformOverview` ([PlatformOverview](/builders/api-schema/types-m-r/#platformoverview)) — Platform-wide overview metrics for the given time range.
  - `timeRange`: `TimeRangeInput` ([TimeRangeInput](/builders/api-schema/types-s-z/#timerangeinput)) — Time range for the overview.
- **usage**: `AnalyticsUsage!` ([AnalyticsUsage](/builders/api-schema/types-a-f/#analyticsusage)) — Usage analytics: streaming hours, storage, and processing.
- **health**: `AnalyticsHealth!` ([AnalyticsHealth](/builders/api-schema/types-a-f/#analyticshealth)) — Health analytics: stream quality, rebuffering, client QoE.
- **lifecycle**: `AnalyticsLifecycle!` ([AnalyticsLifecycle](/builders/api-schema/types-a-f/#analyticslifecycle)) — Lifecycle analytics: stream events, artifacts, connections.
- **infra**: `AnalyticsInfra!` ([AnalyticsInfra](/builders/api-schema/types-a-f/#analyticsinfra)) — Infrastructure analytics: routing, node metrics, services.

## DVRChapterMode

**enum**

DVR historical chapter mode. Determines how chapter (startMs, endMs) ranges are produced for finalized replay artifacts. Configured at the Stream level via updateStream and snapshotted onto the DVR artifact at StartDVR. UTC-only — civil-time chapters resolve at the edge.

## DVRChapterState

**enum**

Chapter finalization state machine. Chapter playback resolves to the chapter artifact&#39;s playbackId once state &gt;= FINALIZED.

- `OPEN` — Recording in progress (chapter sweeper opened the boundary).
- `CLOSED` — Boundary reached; awaiting finalization.
- `FINALIZING` — Processing job in flight on the recording origin.
- `FINALIZED` — Chapter artifact produced; not yet synced to S3.
- `FROZEN` — Chapter artifact + .dtsh synced to S3; safe to reclaim source segments.
- `RECLAIMED` — Source segments deleted; row remains as metadata. Playback uses the artifact.
- `FAILED_SOURCE_MISSING` — Recovery exhausted — at least one source segment was missing from both local and the recovery freeze.
- `FAILED_PERMANENT` — Unrecoverable input (ledger invariants violated, repeated retries exhausted).
