## ClipCreationMode

**enum**

Clip creation mode determines how time fields are interpreted.

- `ABSOLUTE` — Use startUnix and stopUnix as Unix timestamps in seconds.
- `RELATIVE` — Use startMedia and stopMedia as seconds from stream start.
- `DURATION` — Use startUnix (or startMedia) plus duration.
- `CLIP_NOW` — Clip the last N seconds from the current live position.

## CreateClipInput

**input_object**

- **streamId**: `ID!` — Stream to create the clip from (Stream.id, Relay global ID).

- **stopUnix**: `Int` — End time as Unix timestamp (ABSOLUTE mode).
- **startMedia**: `Int` — Start time as seconds from stream start (RELATIVE mode).
- **stopMedia**: `Int` — End time as seconds from stream start (RELATIVE mode).
- **duration**: `Int` — Clip duration in seconds (DURATION/CLIP_NOW mode).
- **expiresAt**: `Int` — Optional expiration as Unix timestamp.
- **startTime**: `Int` — Deprecated: Use startUnix instead. **Deprecated:** Use startUnix instead
- **endTime**: `Int` — Deprecated: Use stopUnix instead. **Deprecated:** Use stopUnix instead

## DVRChapter

**object**

A single chapter view of a DVR recording. playbackId is the Commodore-minted public key for the chapter&#39;s VOD-shaped artifact; chapter playback uses the same artifact playback path as any VOD (not dvr+).

- **chapterId**: `ID!`
- **state**: `DVRChapterState!` ([DVRChapterState](/builders/api-schema/media-types/#dvrchapterstate))
- **playbackId**: `String` — Public playback key minted by Commodore; null until finalization dispatches.
- **isCurrent**: `Boolean!`
- **hasGaps**: `Boolean!`
- **segmentCount**: `Int!`
- **wallClockStartUnixMs**: `Float!` — Absolute Unix epoch ms of the playable MKV span start; falls back to the scheduled chapter start before finalization.
- **wallClockEndUnixMs**: `Float!` — Absolute Unix epoch ms of the playable MKV span end; falls back to the scheduled chapter end before finalization.
- **playableNow**: `Boolean!` — True when state ∈ &#123;FINALIZED, FROZEN, RECLAIMED&#125;.
- **lastFailureReason**: `String` — Last finalization failure message (operator-facing); null on success or in-progress.

## DVRChapterState

**enum**

Chapter finalization state machine. Chapter playback resolves to the chapter artifact&#39;s playbackId once state &gt;= FINALIZED.

- `OPEN` — Recording in progress (chapter sweeper opened the boundary).
- `CLOSED` — Boundary reached; awaiting finalization.
- `FINALIZING` — Processing job in flight on the recording origin.
- `FINALIZED` — Chapter artifact produced; not yet synced to S3.
- `FROZEN` — Chapter artifact + .dtsh synced to S3; safe to reclaim source segments.
- `RECLAIMED` — Source segments deleted; row remains as metadata. Playback uses the artifact.
- `FAILED_SOURCE_MISSING` — Recovery exhausted — at least one source segment was missing from both local and the recovery freeze.
- `FAILED_PERMANENT` — Unrecoverable input (ledger invariants violated, repeated retries exhausted).

Null for tenants without a storage meter (self-hosted, fully tenant-private clusters). Computed from sizeBytes in GiB × unit_price_per_gb_hour × hours_held.

- **status**: `String`
- **startedAt**: `Time` ([Time](/builders/api-schema/shared/#time))

- **storageLocation**: `String`
- **syncStatus**: `String` — Current S3 sync state (pending, in_progress, synced, failed, lost_local).
- **hasLocalCopy**: `Boolean` — Present full local node copy (origin or cache): true when at least one node holds a complete local copy, false when none remain (playback via read-through relay from S3). Null when the placement overlay (Periscope) is unavailable — unknown, not &#39;no local copy&#39;. Durable S3-only state is derived by consumers as isSynced &amp;&amp; hasLocalCopy == false.
- **isSynced**: `Boolean` — True when S3 has an authoritative copy.
- **isFinalized**: `Boolean` — True when the S3 copy includes the Mist .dtsh index.
- **frozenAt**: `Time` ([Time](/builders/api-schema/shared/#time))

- **thumbnailAssets**: `ThumbnailAssets` ([ThumbnailAssets](/builders/api-schema/shared/#thumbnailassets)) — Server-resolved Chandler URLs for the DVR&#39;s poster and sprite thumbnails. Null until Foghorn confirms the thumbnail upload.
