### Query.dvrChapter

Retrieve a single DVR chapter, including its finalized playbackId. Chapters are produced by the finalization queue as canonical .mkv VOD artifacts. Historical chapter mode is configured at the Stream level (Stream.dvrChapterMode) and snapshotted at StartDVR. Modes: - WINDOW_SIZED: sequential fixed-length chapters of size tier.MaxWindowSeconds since the recording&#39;s start. - FIXED_INTERVAL: UTC-only buckets of intervalSeconds, anchored at unix epoch 0.

```graphql
dvrChapter(
  dvrId: ID!
  mode: DVRChapterMode
  intervalSeconds: Int
  startMs: Float!
  endMs: Float!
): DVRChapter
```

**Returns:** `DVRChapter` ([DVRChapter](/builders/api-schema/media-types/#dvrchapter))

**Arguments**

- `dvrId`: `ID!` — DVR recording identifier — accepts either DVRRequest.id (UUID) or DVRRequest.dvrHash.
- `mode`: `DVRChapterMode` ([DVRChapterMode](/builders/api-schema/shared/#dvrchaptermode)) — Historical chapter mode; null defaults to the recording&#39;s policy snapshot.
- `intervalSeconds`: `Int` — Required for FIXED_INTERVAL mode.
- `startMs`: `Float!` — UTC epoch milliseconds (start of range).
- `endMs`: `Float!` — UTC epoch milliseconds (end of range, exclusive).

**SDK**

| Operation | TypeScript | Go | Python |
| --- | --- | --- | --- |
| GetDVRChapter | `GetDVRChapterDocument` | `GetDVRChapter` | `get_dvr_chapter` |

### Query.dvrChapters

List chapters for a DVR recording. Paginated for unbounded artifact lifetime — default 200 per page, max 1000.

```graphql
dvrChapters(
  dvrId: ID!
  mode: DVRChapterMode
  intervalSeconds: Int
  rangeStartMs: Float
  rangeEndMs: Float
  pageSize: Int
  pageToken: String
): DVRChaptersPage
```

**Returns:** `DVRChaptersPage` ([DVRChaptersPage](/builders/api-schema/media-types/#dvrchapterspage))

**Arguments**

- `dvrId`: `ID!` — DVR recording identifier — accepts either DVRRequest.id (UUID) or DVRRequest.dvrHash.
- `mode`: `DVRChapterMode` ([DVRChapterMode](/builders/api-schema/shared/#dvrchaptermode)) — Restrict to chapters of this mode; null = all.
- `intervalSeconds`: `Int` — Required when filtering by FIXED_INTERVAL.
- `rangeStartMs`: `Float` — UTC epoch ms lower bound; 0 = no lower bound.
- `rangeEndMs`: `Float` — UTC epoch ms upper bound; 0 = no upper bound.
- `pageSize`: `Int` — Default 200. Max 1000.
- `pageToken`: `String` — Keyset cursor from a previous page&#39;s nextPageToken.

**SDK**

### Mutation.setMediaRetentionPolicy

Set the tenant per-class retention default. `targetType` picks the asset class (VOD, DVR, or CLIP). `days` is in [0, tier cap] where 0 means &#34;keep forever&#34; — only honored on uncapped (paid) tiers; Free clamps to its cap at write time. `clear: true` NULLs the column so the tenant inherits the per-class system default (VOD: keep forever; DVR/clip: 30d). The tier cap is exposed via `mediaRetentionPolicy.bounds.maxRecordingRetentionDays`.

```graphql
setMediaRetentionPolicy(
  input: SetMediaRetentionPolicyInput!
```
