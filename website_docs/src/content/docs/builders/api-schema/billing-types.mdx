## BalanceTransaction

**object**

A single balance transaction (top-up, usage deduction, refund, etc.).

- **id**: `ID!` — Unique transaction identifier.
- **tenantId**: `String!` — Owning tenant identifier.
- **amountCents**: `Int!` — Amount in cents (positive = credit, negative = debit).
- **balanceAfterCents**: `Int!` — Balance after this transaction.
- **transactionType**: `String!` — Transaction type: topup, usage, refund, adjustment.
- **description**: `String` — Human-readable description.
- **referenceId**: `String` — Reference to related object (crypto payment, usage record, etc.).
- **referenceType**: `String` — Type of the referenced object.
- **createdAt**: `Time!` ([Time](/builders/api-schema/shared/#time)) — When the transaction occurred.

## BillingDetails

**object**

Billing details for a tenant. These are optional for Free and small simplified top-ups, and required when paid postpaid collection or a full invoice needs them.

- **email**: `String` — Billing contact email.
- **name**: `String` — Customer legal or person name shown on full invoices.
- **company**: `String` — Company name for invoices.
- **vatNumber**: `String` — VAT number (EU format: XX123456789).
- **address**: `BillingAddress` ([BillingAddress](/builders/api-schema/billing-types/#billingaddress)) — Structured billing address.
- **isComplete**: `Boolean!` — True if all full-invoice fields are present (legal name + email + address).
- **updatedAt**: `Time` ([Time](/builders/api-schema/shared/#time)) — When billing details were last updated.
- **presentmentCurrency**: `Currency` ([Currency](/builders/api-schema/billing-types/#currency)) — Currency the tenant is invoiced and charged in (EUR, USD, GBP), derived from the billing address country. It cannot change while a provider subscription, an open invoice, or a card first payment started in the last day exists.

## BillingFeatures

**object**

Contractual and enforced properties of a billing tier. Usage limits are entitlements, not features.

- **supportLevel**: `String!` — Support level (community, email, priority, dedicated).
- **sla**: `Boolean!` — Whether SLA guarantees apply.
- **processingCustomizable**: `Boolean!` — Whether the tenant may override the tier&#39;s processing profiles.

## BillingTier

**object**

A subscription tier defining pricing rules, entitlements, and features. Tenants subscribe to a tier which determines their billing and capabilities.

- **id**: `ID!` — Unique tier identifier.
- **tierName**: `String!` — Internal tier name (payg, free, supporter, developer, production, enterprise).
- **tierLevel**: `Int!` — Numeric ordering of tiers; 0 = payg (prepaid), 1 = free, 5 = enterprise. Used to compare upgrade vs downgrade direction.
- **displayName**: `String!` — User-facing tier name.
- **description**: `String` — Tier description for marketing.
- **basePrice**: `Float!` — Base monthly price.
- **currency**: `String!` — Currency code (USD, EUR, etc.).
- **billingPeriod**: `String!` — Billing period (monthly, yearly).
- **features**: `BillingFeatures!` ([BillingFeatures](/builders/api-schema/billing-types/#billingfeatures)) — Feature flags for this tier.
- **pricingRules**: `[PricingRule!]!` ([PricingRule](/builders/api-schema/billing-types/#pricingrule)) — Priced behaviors per meter (rating engine input).
- **entitlements**: `[EntitlementEntry!]!` ([EntitlementEntry](/builders/api-schema/billing-types/#entitlemententry)) — Non-billing grants (e.g. recording_retention_days). Values are JSON-encoded strings.
- **supportLevel**: `String` — Support level included (community, email, priority, dedicated).
- **slaLevel**: `String` — SLA guarantee level for enterprise tiers.
- **meteringEnabled**: `Boolean!` — Whether usage metering is enabled for this tier.
- **isEnterprise**: `Boolean!` — Whether this is an enterprise tier with custom terms.

## ChangeBillingTierPayload

**object**

Result of a postpaid tier change. Either appliedTier is set (immediate upgrade) or pendingTier + effectiveAt are set (scheduled downgrade at period end).

- **success**: `Boolean!` — Whether the request was accepted.
- **message**: `String!` — Human-readable status message.
- **appliedTier**: `BillingTier` ([BillingTier](/builders/api-schema/billing-types/#billingtier)) — Set on immediate upgrade — the new active tier.
- **pendingTier**: `BillingTier` ([BillingTier](/builders/api-schema/billing-types/#billingtier)) — Set on scheduled downgrade — the staged target tier.
- **effectiveAt**: `Time` ([Time](/builders/api-schema/shared/#time)) — When a scheduled downgrade will take effect.

## CryptoAsset

**enum**

Supported crypto assets for top-up (ETH network only).

- `ETH` — Native Ethereum
- `USDC` — USDC stablecoin (ERC-20)
- `LPT` — Livepeer Token (ERC-20). Currently reserved — prepaid top-ups gated until a non-Chainlink price source is wired.

## CryptoTopupResult

**object**

Result from creating a crypto top-up. The price is locked at this response. Send exactly `expectedAmountToken` of `asset` to `depositAddress`; on confirmation, the balance is credited at `quotedPriceUsd` regardless of price drift inside the address TTL.

- **topupId**: `ID!` — Internal top-up ID for tracking/polling.
- **depositAddress**: `String!` — HD-derived Ethereum address to send funds to.
- **asset**: `CryptoAsset!` ([CryptoAsset](/builders/api-schema/billing-types/#cryptoasset)) — Asset to send (ETH or USDC).
- **assetSymbol**: `String!` — Human-readable asset symbol (&#34;ETH&#34; &#124; &#34;USDC&#34;).
- **expectedAmountCents**: `Int!` — Echo of input amountCents, in cents of the tenant&#39;s presentment currency.
- **expiresAt**: `Time!` ([Time](/builders/api-schema/shared/#time)) — When this deposit address expires (24 hours from creation).
- **expectedAmountBaseUnits**: `String!` — Token base units to send (decimal string; wei for 18-decimal assets).
- **expectedAmountToken**: `String!` — Human-friendly decimal of expectedAmountBaseUnits, e.g. &#34;0.01515&#34;.
- **quotedPriceUsd**: `String!` — Locked USD price per 1 whole token, e.g. &#34;3300.45&#34;.
- **quoteSource**: `String!` — Source of the price quote (&#34;chainlink&#34; &#124; &#34;one_to_one&#34;).
- **quotedAt**: `Time!` ([Time](/builders/api-schema/shared/#time)) — When the price was locked.
- **network**: `String!` — Network the deposit address lives on (&#34;ethereum&#34; &#124; &#34;arbitrum&#34; &#124; &#34;base&#34;).
- **conversion**: `CurrencyConversion` ([CurrencyConversion](/builders/api-schema/billing-types/#currencyconversion)) — Presentment amount and the EUR credit it converts to, locked with the quote.

- **txHash**: `String` — Blockchain transaction hash (when detected).
- **confirmations**: `Int!` — Number of block confirmations.
- **receivedAmountBaseUnits**: `String` — Amount received in token base units (decimal string).
- **receivedAmountToken**: `String` — Human-friendly decimal of receivedAmountBaseUnits.
- **creditedAmountCents**: `Int` — Amount credited to balance in `creditedAmountCurrency` cents.
- **creditedAmountCurrency**: `String` — Ledger currency of the credit, EUR.
- **quoteSource**: `String` — Source of the locked price quote (&#34;chainlink&#34; &#124; &#34;one_to_one&#34;).
- **network**: `String` — Network the deposit address lives on.
- **expiresAt**: `Time!` ([Time](/builders/api-schema/shared/#time)) — When the deposit address expires.
- **detectedAt**: `Time` ([Time](/builders/api-schema/shared/#time)) — When payment was first detected on-chain.
- **completedAt**: `Time` ([Time](/builders/api-schema/shared/#time)) — When balance was credited.
- **conversion**: `CurrencyConversion` ([CurrencyConversion](/builders/api-schema/billing-types/#currencyconversion)) — Presentment amount and the EUR credit it converts to, locked with the quote.

## CurrencyConversion

**object**

Conversion of a payment into the EUR prepaid ledger and invoice currency. EUR amounts use the identity rate.

- **originalAmountCents**: `Int!` — Amount charged, in cents of `originalCurrency`.
- **originalCurrency**: `Currency!` ([Currency](/builders/api-schema/billing-types/#currency)) — Currency charged (EUR, USD, GBP).
- **eurAmountCents**: `Int!` — EUR cents credited or applied.
- **unitsPerEur**: `String!` — Units of `originalCurrency` one euro buys, as a decimal string (&#34;1&#34; for EUR).
- **source**: `String!` — Rate source: identity (EUR), ecb (ECB reference rate), or legacy_quote (USD rate quoted before ECB rates were stored).
- **referenceDate**: `String!` — ECB reference date of the rate (YYYY-MM-DD).

## Invoice

**object**

A billing invoice for a subscription period. Includes base subscription and metered usage charges. Amounts are computed in EUR; a finalized invoice is presented and charged in the tenant&#39;s presentment currency at the ECB rate of its finalization date.

- **id**: `ID!` — Unique invoice identifier.
- **amount**: `Money!` ([Money](/builders/api-schema/billing-types/#money)) — Total amount due in EUR (after credits applied).
- **baseAmount**: `Money!` ([Money](/builders/api-schema/billing-types/#money)) — Base subscription amount in EUR.
- **meteredAmount**: `Money!` ([Money](/builders/api-schema/billing-types/#money)) — Metered usage charges in EUR (net; 0 while usage is waived during beta).
- **grossMeteredAmount**: `Money!` ([Money](/builders/api-schema/billing-types/#money)) — Unwaived metered total — what usage would have cost. Equals meteredAmount when usage is not waived; the would-have-cost figure when it is.
- **prepaidCreditApplied**: `Money!` ([Money](/builders/api-schema/billing-types/#money)) — Prepaid balance credit applied to this invoice, in EUR.
- **currency**: `Currency!` ([Currency](/builders/api-schema/billing-types/#currency)) — Currency of the amounts above, EUR.
- **presentmentAmountCents**: `Int` — Total charged, in cents of `presentmentCurrency`. Null until the invoice is finalized.
- **presentmentCurrency**: `String` — Currency the invoice is presented and charged in (EUR, USD, GBP). Empty until the invoice is finalized.
- **presentmentUnitsPerEur**: `String` — Units of `presentmentCurrency` one euro buys at finalization, as a decimal string. Empty until the invoice is finalized.
- **presentmentReferenceDate**: `String` — ECB reference date of the presentment rate (YYYY-MM-DD). Empty until the invoice is finalized.
- **finalizedAt**: `Time` ([Time](/builders/api-schema/shared/#time)) — When the invoice was finalized and its presentment amount fixed.
- **status**: `InvoiceStatus!` ([InvoiceStatus](/builders/api-schema/billing-types/#invoicestatus)) — Invoice status (draft, open, paid, void).
- **dueDate**: `Time!` ([Time](/builders/api-schema/shared/#time)) — Payment due date.
- **paidAt**: `Time` ([Time](/builders/api-schema/shared/#time)) — When payment was received.
- **createdAt**: `Time!` ([Time](/builders/api-schema/shared/#time)) — When the invoice was created.
- **updatedAt**: `Time!` ([Time](/builders/api-schema/shared/#time)) — When the invoice was last updated.
- **periodStart**: `Time` ([Time](/builders/api-schema/shared/#time)) — Billing period start date.
- **periodEnd**: `Time` ([Time](/builders/api-schema/shared/#time)) — Billing period end date.
- **usageDetails**: `JSON` ([JSON](/builders/api-schema/shared/#json)) — Detailed usage breakdown (JSON).
- **lineItems**: `[LineItem!]!` ([LineItem](/builders/api-schema/billing-types/#lineitem)) — Individual line items on the invoice.

## LineItem

**object**

A single line item on an invoice or usage preview, produced by the rating engine. Decimal quantities are strings to preserve precision.

- **lineKey**: `String!` — Stable identity: &#39;base_subscription&#39;, &#39;meter:&lt;name&gt;:&lt;cluster_id&gt;:&lt;yyyymm&gt;&#39;.
- **meter**: `String!` — Meter name; empty for base_subscription.
- **description**: `String!` — Description of the charge.
- **quantity**: `String!` — Total quantity used (decimal as string).
- **includedQuantity**: `String!` — Free quantity (decimal as string).
- **billableQuantity**: `String!` — Billable quantity (decimal as string).
- **unitPrice**: `String!` — Price per unit (decimal as string).
- **total**: `String!` — Total for this line item (= billableQuantity * unitPrice), decimal as string.
- **currency**: `String!` — Currency (ISO 4217).
- **clusterId**: `String` — Cluster id this line was attributed to; null for tenant-scoped lines (base_subscription).
- **clusterName**: `String` — Display name of the cluster, joined from Quartermaster at read time. Null when clusterId is null.
- **clusterKind**: `String` — platform_official &#124; tenant_private &#124; third_party_marketplace; null when clusterId is null.
- **pricingSource**: `String!` — Why the line was priced as it was: tier, cluster_metered, cluster_monthly, cluster_custom, free_unmetered, self_hosted, included_subscription.
- **pricingLabel**: `String!` — Human-readable label of pricingSource (e.g. &#39;Self-hosted (no charge)&#39;, &#39;Marketplace metered&#39;). Empty when not populated by the gateway.
- **unit**: `String!` — Canonical quantity unit.
- **dimensions**: `JSON!` ([JSON](/builders/api-schema/shared/#json)) — Bounded pricing dimensions such as codec, rendition, backend, or model.

## PaymentMethod

**enum**

Supported payment methods.

- `CARD` — Credit/debit card via the configured card provider.
- `CRYPTO_ETH` — Ethereum invoice payment.
- `CRYPTO_USDC` — USDC invoice payment.

## PaymentStatus

**enum**

Payment processing status.

- `PENDING` — Payment initiated, awaiting confirmation.
- `CONFIRMED` — Payment successfully processed.
- `FAILED` — Payment failed or declined.

## PrepaidBalance

**object**

Prepaid balance for wallet-based accounts. Wallet-only accounts MUST use prepaid billing (balance-based, pay first).

- **id**: `ID!` — Unique balance record identifier.
- **tenantId**: `String!` — Owning tenant identifier.
- **balanceCents**: `Int!` — Settled ledger balance in cents before active usage reservations.
- **reservedBalanceCents**: `Int!` — Active in-flight usage reservations in cents.
- **availableBalanceCents**: `Int!` — Spendable balance after active reservations (balanceCents - reservedBalanceCents).
- **currency**: `String!` — Ledger currency, always EUR.
- **lowBalanceThresholdCents**: `Int!` — Alert threshold in cents.
- **isLowBalance**: `Boolean!` — True if available balance is below threshold.
- **drainRateCentsPerHour**: `Int!` — Estimated spend rate in cents per hour (based on last hour&#39;s usage).
- **createdAt**: `Time!` ([Time](/builders/api-schema/shared/#time)) — When the balance was created.
- **updatedAt**: `Time!` ([Time](/builders/api-schema/shared/#time)) — When the balance was last updated.

## PricingRule

**object**

A pricing rule: how a meter rates to money. Decimal fields are strings to preserve precision.

- **meter**: `String!` — Canonical meter name (for example delivered_minutes, storage_gb_seconds_cold, media_seconds, or a marketplace-defined meter).
- **model**: `String!` — Pricing model (tiered_graduated, all_usage, dimensioned).
- **currency**: `String!` — Currency (ISO 4217).
- **includedQuantity**: `String!` — Free quantity included before billing kicks in.
- **unitPrice**: `String!` — Price per unit (decimal as string).
- **configJson**: `String!` — Model-specific config (for example dimension selector rates); JSON-encoded.
