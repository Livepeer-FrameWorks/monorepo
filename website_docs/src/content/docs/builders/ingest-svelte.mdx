## Installation

```bash
npm install @livepeer-frameworks/streamcrafter-svelte
```

Import the CSS once in your app:

```svelte
<script>
  import "@livepeer-frameworks/streamcrafter-svelte/streamcrafter.css";
</script>
```

## Drop-in Component

The `<StreamCrafter />` component is fully self-contained.

**Direct WHIP Mode:**

```svelte
<script lang="ts">
  import { StreamCrafter } from "@livepeer-frameworks/streamcrafter-svelte";
  import "@livepeer-frameworks/streamcrafter-svelte/streamcrafter.css";
</script>

<StreamCrafter whipUrl="%INGEST_URL%/webrtc/stream-key" initialProfile="broadcast" />
```

**Gateway Resolution Mode:**

```svelte
<StreamCrafter gatewayUrl="%GATEWAY_URL%/graphql" streamKey="abc-123" initialProfile="broadcast" />
```

Gateway resolution calls the public `resolveIngestEndpoint` GraphQL field from the publisher's
browser, so routing reflects the publisher's location. For backend or encoder-side publishing, use
the dashboard DNS ingest URL or Foghorn's `/ingest/{streamKey}` front door instead.

### Props

| Prop                | Type                                       | Default       | Description                                                                                                                              |
| ------------------- | ------------------------------------------ | ------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| `whipUrl`           | `string`                                   | —             | Direct WHIP endpoint; takes priority over `gatewayUrl`                                                                                   |
| `resolveWhipUrl`    | `(signal: AbortSignal) => Promise<string>` | —             | Refresh the destination right before each connection                                                                                     |
| `gatewayUrl`        | `string`                                   | —             | Gateway GraphQL endpoint, used with `streamKey`                                                                                          |
| `streamKey`         | `string`                                   | —             | Stream key for gateway resolution                                                                                                        |
| `initialProfile`    | `QualityProfile`                           | `"broadcast"` | Starting quality preset                                                                                                                  |
| `autoStartCamera`   | `boolean`                                  | `false`       | Start the camera once an endpoint is known                                                                                               |
| `enableCompositor`  | `boolean`                                  | `true`        | Run the compositor for layouts, scenes and overlays                                                                                      |
| `compositorConfig`  | `Partial<CompositorConfig>`                | `{}`          | Compositor renderer and output size                                                                                                      |
| `initialLayout`     | `StudioLayout \| null`                     | —             | Layout to start the compositor from; see [Saving and Restoring the Layout](/builders/ingest-compositor/#saving-and-restoring-the-layout) |
| `onLayoutChange`    | `(layout: StudioLayout) => void`           | —             | Called shortly after the scenes, overlays or layout preset change                                                                        |
| `showProducerPanel` | `boolean`                                  | `true`        | Scene, layer, overlay and media controls while the compositor runs                                                                       |
| `showSettings`      | `boolean`                                  | `false`       | Open the quality popup on mount                                                                                                          |
| `devMode`           | `boolean`                                  | `false`       | Debug rows in the quality popup and the Advanced panel in the context menu                                                               |
| `debug`             | `boolean`                                  | `false`       | Debug logging                                                                                                                            |
| `theme`             | `FwThemePreset \| StudioThemeOverrides`    | —             | Theme preset or token overrides                                                                                                          |
| `locale`            | `StudioLocale`                             | `"en"`        | UI language                                                                                                                              |
| `class`             | `string`                                   | `""`          | Extra class on the root                                                                                                                  |
| `onStateChange`     | `(state, context?) => void`                | —             | Lifecycle state changes                                                                                                                  |
| `onError`           | `(error: string) => void`                  | —             | Errors                                                                                                                                   |
| `children`          | `Snippet`                                  | —             | Replaces the built-in UI with your own layout                                                                                            |

## Producer Controls

The producer panel is on by default and appears once the compositor runs: scenes with their
transition, the layers of the active scene, logo and text overlays, and the media files in the mix.
Add Media File sits in the action bar next to Add Camera. The Audio section and, while live, the
connection health pill are always part of the drop-in UI.

```svelte
<!-- Simple single-camera studio without the producer panel -->
<StreamCrafter whipUrl="%INGEST_URL%/webrtc/stream-key" showProducerPanel={false} />
```

The context menu's **Copy WHIP URL** copies the full URL, which contains the stream key. **Copy
Stream Info** masks the key.

## Composable Components

Pass a `children` snippet to replace the default UI with sub-components:

```svelte
<script lang="ts">
  import {
    StreamCrafter,
    StudioPreview,
    StudioMixer,
    StudioActionBar,
    StudioSettings,
    StudioStatusBadge,
  } from "@livepeer-frameworks/streamcrafter-svelte";
  import "@livepeer-frameworks/streamcrafter-svelte/streamcrafter.css";

  const whipUrl = "%INGEST_URL%/webrtc/my-key";
</script>

<StreamCrafter {whipUrl}>
  {#snippet children()}
    <div class="my-layout">
      <StudioStatusBadge />
      <StudioPreview />
      <div class="sidebar">
        <StudioMixer />
        <StudioSettings />
      </div>
      <StudioActionBar {whipUrl} showSettingsButton={false} />
    </div>
  {/snippet}
</StreamCrafter>
```

Sub-components connect to the parent `<StreamCrafter>` through Svelte context, including its
compositor, so `<StudioProducerPanel />` and `<StudioAudioControls />` need no props.
`StudioActionBar` enables Go Live only when it is given the `whipUrl`.

### Sub-Component Reference

| Component                | Purpose                                                                        |
| ------------------------ | ------------------------------------------------------------------------------ |
| `StudioPreview`          | Video preview with optional compositor overlay and live badge                  |
| `StudioMixer`            | Source list with volume sliders, mute, and remove buttons                      |
| `StudioActionBar`        | Add Camera, Share Screen, Add Media File, Settings, and Go Live                |
| `StudioSettings`         | Quality profile and encoder settings popup                                     |
| `StudioStatusBadge`      | State badge (Idle, Capturing, Live, etc.)                                      |
| `StudioConnectionHealth` | Good, unstable or poor while live, with bitrate, loss and round trip           |
| `StudioProducerPanel`    | Scenes, layers, overlays and media; renders nothing until the compositor runs  |
| `SceneSwitcher`          | Scene tiles with transition type and duration                                  |
| `LayerList`              | Layers of a scene: visibility, order, opacity and removal                      |
| `StudioOverlayControls`  | Logo and text overlays of the active scene                                     |
| `StudioMediaControls`    | Play, pause and loop for media files in the mix                                |
| `StudioAudioControls`    | Browser processing, noise gate, de-esser, EQ and ducking                       |
| `CameraPicker`           | Add Camera, with a list when there is more than one camera or one is live      |
| `MediaFileButton`        | Add Media File; turned off with the reason where the browser cannot play files |
| `CompositorControls`     | Layout and scaling selector over the preview                                   |
| `AdvancedPanel`          | Dev-mode panel with stats, encoder overrides and compositor details            |

## Custom UI with Stores

For complete UI control, use `createStreamCrafterContextV2`:

```svelte
<script lang="ts">
  import { onMount, onDestroy } from "svelte";
  import { createStreamCrafterContextV2 } from "@livepeer-frameworks/streamcrafter-svelte";

  const crafter = createStreamCrafterContextV2();
  let videoEl: HTMLVideoElement;

  onMount(() => {
    crafter.initialize({
      whipUrl: "%INGEST_URL%/webrtc/key",
      profile: "broadcast",
      reconnection: { enabled: true },
    });
  });

  onDestroy(() => crafter.destroy());
</script>

<div>
  <video bind:this={videoEl} autoplay muted />
  <p>State: {$crafter.state}</p>
  <p>Sources: {$crafter.sources.length}</p>
  <button onclick={() => crafter.startCamera()}>Add Camera</button>
  <button onclick={() => crafter.startScreenShare({ audio: true })}>Share Screen</button>
  <button
    onclick={() => ($crafter.isStreaming ? crafter.stopStreaming() : crafter.startStreaming())}
  >
    {$crafter.isStreaming ? "Stop" : "Go Live"}
  </button>
</div>
```

<Aside type="note" title="Gateway in custom UI">
  `createStreamCrafterContextV2` accepts `whipUrl` directly. If your environment supports
  `resolveIngestEndpoint`, resolve a WHIP URL first with `IngestClient` from
  `@livepeer-frameworks/streamcrafter-core`. Do this in the publisher client when you want geo
  routing based on the publisher location.
</Aside>

### Store Properties

The store implements Svelte's store contract. Read reactive state with `$crafter` in markup or
subscribe manually in script:

| Property         | Type                  | Description               |
| ---------------- | --------------------- | ------------------------- |
| `state`          | `IngestState`         | Current lifecycle state   |
| `isStreaming`    | `boolean`             | Whether currently live    |
| `isCapturing`    | `boolean`             | Whether media is captured |
| `isReconnecting` | `boolean`             | Whether reconnecting      |
| `sources`        | `MediaSource[]`       | Active media sources      |
| `mediaStream`    | `MediaStream \| null` | Combined output stream    |
| `qualityProfile` | `QualityProfile`      | Current quality settings  |

### Store Methods

| Method                       | Description                       |
| ---------------------------- | --------------------------------- |
| `startCamera(opts?)`         | Add camera source                 |
| `startScreenShare(opts?)`    | Add screen share source           |
| `startStreaming()`           | Go live                           |
| `stopStreaming()`            | Stop streaming                    |
| `removeSource(id)`           | Remove a source                   |
| `setSourceVolume(id, vol)`   | Set source volume (0-2)           |
| `setSourceMuted(id, muted)`  | Mute/unmute source                |
| `setQualityProfile(name)`    | Change quality profile            |
| `getCameraChoices()`         | Cameras, with those in use marked |
| `addMediaFile(file, opts?)`  | Play a local file into the mix    |
| `playMediaSource(id)`        | Play a media file                 |
| `pauseMediaSource(id)`       | Pause a media file                |
| `setMediaSourceLoop(id, on)` | Loop a media file                 |
| `getController()`            | Direct controller access          |

The controller from `getController()` sets the noise gate, EQ and de-esser with
`setAudioProcessing()` and ducking with `setAudioDucking()`; see
[Advanced Features](/builders/ingest-advanced/#audio-processing).
